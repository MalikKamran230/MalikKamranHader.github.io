# Professional Software Engineer Portfolio

A modern, responsive, and animated personal portfolio website built with HTML, CSS, and JavaScript.

## ✨ Features

### 🎨 Design & Animation
- **Dark Theme with Glassmorphism**: Modern dark color scheme with subtle transparency effects
- **Smooth Animations**: AOS.js powered scroll-triggered animations
- **Typewriter Effect**: Animated text introduction in the hero section
- **Parallax Scrolling**: Subtle parallax effect on the hero background
- **Hover Effects**: Interactive project cards with smooth transitions
- **Responsive Design**: Fully responsive across desktop, tablet, and mobile devices

### 📱 Sections
1. **Hero Section**: Full-screen introduction with profile image placeholder
2. **Projects Section**: 6 featured projects with icons and descriptions
3. **About Section**: Professional background and skills showcase
4. **Contact Section**: Contact information and social media links
5. **Footer**: Social media links and copyright information

### 🛠️ Technologies Used
- HTML5 (Semantic structure)
- CSS3 (Modern styling with gradients and animations)
- Vanilla JavaScript (Interactive features)
- AOS.js (Scroll animations)
- Font Awesome (Icons)
- Google Fonts (Inter font family)

## 🚀 Getting Started

### 1. Customize Personal Information
Replace the placeholder text in `home.html`:

```html
<!-- Replace [Your Name] with your actual name -->
<h1 class="typewriter">[Your Name]</h1>

<!-- Update contact information -->
<span>your.email@example.com</span>
<span>linkedin.com/in/yourprofile</span>
<span>github.com/yourusername</span>
```

### 2. Add Your Profile Image
Replace the placeholder icon in the hero section:

```html
<!-- Replace the icon with your actual image -->
<div class="profile-image">
    <img src="path/to/your/image.jpg" alt="Your Name">
</div>
```

### 3. Customize Projects
Update the project descriptions and icons in the projects section to match your actual work.

### 4. Update Skills
Modify the skills section to reflect your actual technical expertise.

## 🎯 Customization Guide

### Colors
The portfolio uses a consistent color scheme:
- Primary: `#64ffda` (Cyan)
- Secondary: `#00d4ff` (Blue)
- Background: Dark gradients
- Text: White and gray variations

### Animations
- AOS animations are applied to sections and elements
- Custom hover effects on project cards and buttons
- Typewriter effect on the main heading
- Parallax scrolling on the hero section

### Responsive Breakpoints
- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px
